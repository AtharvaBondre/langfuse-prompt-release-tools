# Source provenance

This independent MIT project is maintained by Atharva Bondre. Its starting point is the separately published [27-file public Gist](https://gist.github.com/AtharvaBondre/3ad9d0654b5450d1e007728f67047fa0), revision `824e13d8ec01bdee3c3717652ae6852c9aa06dda`, verified on 11 November 2026.

[Source baseline](source-baseline.json) lists the original public filenames and SHA-256 hashes. The repository alpha revises those files; the hashes describe the starting copy, not the current tree. The original Gist remains unchanged.

The Gist's design history covers pull/review/publish verification, then staged label promotion, then application-result receipts. This repository retains that workflow and adds stricter defaults, reliability fixes, distribution checks and a current integration plan. It does not copy private prompts, tenant execution records or unrelated private source.
